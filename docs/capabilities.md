# Supported work and limits

| Function | Local repo | Agent responsibility |
| --- | --- | --- |
| Questionnaire | Saved answers, history, and next three questions | Natural conversation and useful follow-up questions |
| Visual directions | Seven fixed starter boards | Business-specific designs and reasons |
| Symbol | Seven geometric starters and custom primitive input | Original concept, bounds, and visual refinement |
| Construction guides | Grid, axes, bounding reference, and circle | Actual geometry checks and optical corrections |
| Fonts | Bundled Inter and Fraunces previews | Additional font choice, scripts, glyph checks, and exact licenses |
| Colors | HEX palette and contrast ratios | Actual use, unrounded thresholds, and printer proof |
| Logo source | Clean SVG shapes and editable name text | Outline export and comparison |
| Sample approval | Exact file hashes and stale-version checks | Actual owner approval and evidence |
| Brand kit | SVG files, profile, tokens, licenses, and guide | Requested applications and final inspection |
| PNG and PDF | No automatic export | Suitable export tools and visual inspection |
| Commercial name check | No automatic check | Current source checks and qualified review where needed |
| Account access | None | Actual connected tools and user permission |

The agent must report unsupported work before it promises that result.
A catalog preview is not proof of a custom identity.
A sample approval is not final kit approval.
Tests establish code behavior, not the quality of every future business logo.

The engine runs locally without paid services or an AI API key.
The user supplies an agent with the tools required for the job.
Offline use can complete the questionnaire and local exports.
Current research and new external assets need network access.
