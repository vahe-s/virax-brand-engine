# Start your brand in chat

## For the business owner

1. Create a separate agent project for your business.
2. Give the agent this repo or a local copy.
3. Say, “Set up VIRAX Brand Engine for my business.”
4. Answer the questions in your own words.

You can ask the agent for ideas when you do not know an answer.
You can provide references, use original ideas, or combine both paths.
Keep future brand requests in the same project.

If your agent cannot apply project instructions, copy [PROJECT-INSTRUCTIONS.md](PROJECT-INSTRUCTIONS.md) into the supported instruction field.
Keep your profile and approved assets in your private project sources.

## For the agent

1. Read AGENTS.md and docs/agent-workflow.md.
2. Check your actual file, browser, research, vector, and execution tools.
3. Find the current private profile and approved files.
4. Reuse saved answers and current rules.
5. Ask no more than three short questions at once.
6. Save each answer before the next group.
7. Follow docs/questionnaire.md as a guide.
8. Show seven distinct directions that reflect the business brief.
9. Explain the reason for each direction.
10. Help the owner select, combine, or replace the directions.
11. Create one custom logo sample with type, color, and geometry notes.
12. Inspect the sample and show it in chat.
13. Record approval only after the owner approves those exact files.
14. Export the kit and complete its required delivery checks.

Run authorized technical steps yourself when your tools permit them.
Do not require a nontechnical owner to run commands that you can run.
Do not require a browser questionnaire.
Use the HTML boards for visual comparison and review.

Read docs/capabilities.md before you promise a deliverable.
Save temporary task changes separately from lasting brand rules.
Keep the current profile, file hashes, review record, and approved kit together.

## Resume another chat

Give the next agent these private sources:

- The current profile and its version.
- The current brand rules.
- The approved artwork and exact file hashes.
- The current task and unfinished checks.

The public repo does not contain your private profile.
Do not promise permanent memory without a saved source.
